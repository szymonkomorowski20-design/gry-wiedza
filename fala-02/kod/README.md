# Kod do nauki

Trzy wyciągi edukacyjne na licencji MIT. Zachowano oryginalne informacje licencyjne; pliki źródłowe nie zostały zmodyfikowane. Pominięto zewnętrzne biblioteki i grafiki. **Archiwa nie są kompletnymi aplikacjami gotowymi do uruchomienia.** Nie instalowano zależności ani nie testowano działania programów.

- [game-2048](game-2048-wyciag.zip) — Logika planszy, łączenie kafelków i zapis stanu; bez HTML, stylów i fontów. [Pełny projekt](https://github.com/gabrielecirulli/2048/tree/478b6ec346e3787f589e4af751378d06ded4cbbc).
- [ecs-lib](ecs-lib-wyciag.zip) — Encje, komponenty i systemy; wyciąg kodu, dokumentacji i testów. [Pełny projekt](https://github.com/nidorx/ecs-lib/tree/e4738e088e4653b6ae37ad5d45cac0d2e00be6d9).
- [dialogger](dialogger-wyciag.zip) — Edytor grafu dialogów i eksport JSON; bez bibliotek zewnętrznych i grafik. [Pełny projekt](https://github.com/etodd/dialogger/tree/95440945dc1c86206c3d2bc3b2056a289d3717be).
