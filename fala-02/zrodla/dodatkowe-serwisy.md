# Dodatkowe serwisy wskazane do biblioteki

Przegląd z 24 września 2026. „Link” oznacza zapisane źródło, nie pobraną zawartość ani potwierdzenie praw każdego pliku. Poniżej objęto wszystkie dodatkowe propozycje ze zlecenia.

| Źródło | Zastosowanie i wynik przeglądu |
|---|---|
| [r/gameassets](https://www.reddit.com/r/gameassets/) | Odkrywanie paczek społeczności. Nie potwierdzono przytoczonej zasady „na zawsze, bez rejestracji”; warunki sprawdza się u autora. Link. |
| [r/freegameassets](https://www.reddit.com/r/freegameassets/) | Kolejne ogłoszenia paczek, także pixel art. Post nie zastępuje licencji pliku. Link. |
| [r/gamedev](https://www.reddit.com/r/gamedev/) | Dyskusje o produkcji. Nie udało się potwierdzić wskazanego tytułu „The Ultimate FREE Game Dev Asset List (50+ Sites)” ani daty lipiec 2025; nie wymyślono adresu wątku. |
| [FreeGameDev](https://freegamedev.net/) | Społeczność wolnych gier. W tej sesji nie udało się pobrać strony ani potwierdzić konkretnego wątku o przejmowanych projektach. |
| [GameDev.tv — Indie Resources](https://community.gamedev.tv/t/wiki-free-cheap-indie-gamedev-resources/1948) | Historyczne wiki o grafice, audio, kodzie, animacji, planowaniu i GDD. Przetworzono cały pierwszy post; [indeks linków](wiki-linki.md). Część informacji może być nieaktualna. |
| [GameDev.tv — Blender Resources](https://community.gamedev.tv/t/wiki-free-blender-resources/156522) | Materiały, tekstury, modele i HDRI. Przetworzono cały pierwszy post; ten sam indeks, łącznie 159 odnośników z dwóch wiki. |
| [Sonniss GameAudioGDC](https://gdc.sonniss.com/) | Duże zbiory efektów do projektów. [Licencja v2.0, od 27.08.2026](https://sonniss.com/gdc-bundle-license/) ogranicza redystrybucję nagrań jako biblioteki. Nie skopiowano paczek do tego repozytorium. Nie potwierdzano podanych rozmiarów każdej edycji. |
| [Archive.org](https://archive.org/) | Możliwe kopie historyczne; obecność w archiwum nie daje dodatkowego prawa do publikowania SFX ani cudzych gier. Bez masowego pobierania. |
| [Freesound](https://freesound.org/help/faq/) | Nagrania o różnych licencjach. Wyszukuj CC0, a następnie zapisz autora, konkretną stronę dźwięku i deklarację licencji. Sam portal nie jest w całości CC0. Link. |
| [GameSounds](https://gamesounds.xyz/) | Katalog audio. Nie ustalono wspólnej licencji pozwalającej skopiować całą zawartość. Link. |
| [Zapsplat](https://www.zapsplat.com/license-type/standard-license/) | Efekty na własnych warunkach licencyjnych. Nie potraktowano darmowego użycia w projekcie jako prawa do utworzenia kopii biblioteki. Link. |
| [FilmCow](https://filmcow.itch.io/) | Cztery tomy SFX. Pierwsza paczka ma własną licencję i ograniczenia, więc nie jest CC0. [Strona pierwszej paczki](https://filmcow.itch.io/filmcow-sfx); nie kopiowano nagrań. |
| [Signature Sounds](https://signaturesounds.org/) | Dodatkowe audio. Nie potwierdzono licencji całego katalogu ani twierdzenia o jednej cenie za całość. Link do dalszej selekcji. |
| [Poly Haven](https://polyhaven.com/license) | Same assety publikowane są na CC0; przydatne HDRI, modele i materiały. Zapisano jako źródło następnych konkretnych pobrań; nie skopiowano katalogu ani zawartości witryny. |
| [ambientCG](https://docs.ambientcg.com/license/) | CC0. Pobrano sześć materiałów PBR w wariancie 1K JPG: cegła, drewno, ziemia, beton, metal i skała. [Paczki](../paczki/README.md). |
| [Poly Pizza](https://poly.pizza/) | Modele low-poly o różnych licencjach. Przykładowy [City Props](https://poly.pizza/bundle/City-Props-oiCnu8AuUP) wskazuje CC BY; nie można uznać całego portalu za CC0. Link. |
| [The Base Mesh](https://www.thebasemesh.com/model-library) | Bazowe modele do dalszego modelowania. [FAQ potwierdza CC0](https://www.thebasemesh.com/faq); pobrano osiem modeli. Nie przyjęto historycznej liczby „250+” jako aktualnego rozmiaru kolekcji. |
| [Kenney](https://kenney.nl/assets) | Sprawdzone paczki CC0 do prototypów 2D/3D, UI i audio. Osiem nowych paczek w tej fali, dziewięć w poprzedniej. Cztery dalsze próby zakończyły się błędem połączenia — [rejestr](../niepobrane.json). |
| [OpenGameArt](https://opengameart.org/content/faq) | Grafika, modele i audio na różnych licencjach. Należy sprawdzać pojedynczy wpis, autorstwo i wymagania atrybucji. Link. |
| [itch.io — darmowe assety](https://itch.io/game-assets/free) | Odkrywanie paczek twórców. Cena zero nie rozstrzyga o komercyjnym użyciu lub redystrybucji. Konkretna paczka Gothicvania nie została zweryfikowana; nie powielono deklaracji o „10 latach” zawartości. |
| [Quaternius — Ultimate Nature](https://quaternius.com/packs/ultimatenature.html) | Konkretna paczka deklaruje CC0. Strona prowadzi do folderu Google Drive; nie pobrano i nie oznaczono jej jako dostarczonej. |
| [CMU Motion Capture](http://mocap.cs.cmu.edu/) | Źródło ruchu postaci wskazane przez wiki. Import wymaga dopasowania szkieletu, skali i animacji; warunków konkretnego pobrania nie zweryfikowano w tej sesji. |
| [The Obscuritory](https://obscuritory.com/) | Artykuły i badanie historii mniej znanych gier. „Abandonware” nie stanowi licencji na przejęcie grafiki, muzyki ani kodu. Nie skopiowano assetów starych gier. |
| [Archiwum Unreal Wiki](https://unreal.gg-labs.com/wiki-archives) | Historyczne materiały mogą pomóc przy starszych projektach. W tej sesji strona była niedostępna; nie potwierdzono pliku ZIP ani jego licencji. |
| [LibreGames](https://gitlab.com/LibreGames) | Projekty utrzymywane przez społeczność. Licencję kodu, grafiki i muzyki należy sprawdzać w każdym repozytorium osobno; nie skopiowano całej grupy. |

Wiedzę praktyczną z zakresu tych źródeł uporządkowano w [poradnikach](../wiedza/00-mapa-nauki.md). Nie oznacza to przeczytania wszystkich publikacji dostępnych w każdym serwisie.
