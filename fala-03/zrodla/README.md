## Zawartość i granice analizy

Zinwentaryzowano drzewa plików wszystkich 32 repozytoriów. Przetworzono komplet pobranych dokumentów merytorycznych Markdown, w tym podfoldery Mu-L/TMHSDigital, chińskie README haxiomic i archiwum stevinz. Zbadano dane JSON ToxSam. Pliki regulaminów współpracy, konfiguracje i AGENTS.md są metadanymi repozytoriów, nie materiałem szkoleniowym do przeniesienia.

Nie pobierano całej historii Git, komentarzy Gistów, issues ani wszystkich filmów, książek i projektów zewnętrznych. Nie wykonano kodu obcych projektów ani importu paczek do silników. Własne poradniki są praktycznym opracowaniem zakresów, nie deklaracją przeczytania wszystkich podlinkowanych treści.

Strony tematów są zmiennymi wynikami wyszukiwania. Dla `game-engine-dev` pobrana pierwsza strona nie zawierała kart repozytoriów; nie dopisano sztucznych wyników. Pozycje z tematów mają status odnośników, bez potwierdzenia licencji.
